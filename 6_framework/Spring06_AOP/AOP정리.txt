AOP
프로그램은 비즈니스 로직(핵심기능)과 공통 관심사(공통기능)으로 나뉜다.
AOP가 이를 깔끔하게 분리하기 위해 존재한다.

AOP 과정
애플리케이션이 실행되면 스프링 컨테이너는 타겟 객체를 감싸는 프록시 객체를 생성하고 이를 빈으로 등록한다.
이렇게 만들어진 프록시 객체가 타겟 객체를 내부에 보관하고 실제 호출을 가로챈다.
이후 타겟 메소드가 호출되면 프록시 객체의 invoke()메소드가 먼저 실행되어
타겟 메소드 전, 타겟 메소드 실행(invocation.proceed()), 타겟 메소드 후 처리를 순서대로 진행하게 된다.

AOP XML 설정
1. 타겟 객체(비즈니스 로직 담당) bean으로 먼저 생성
<bean id="student" class="com.test02.AOP.Student"/>
<bean id="teacher" class="com.test02.AOP.Teacher"/>

2. MyAspect클래스가 advise 역할 수행.=> 공통관심사항 실행할 객체!
MyAspect는 MethodInterceptor 구현해서 invoke() 가지고 있다.
<bean id="myAdvice" class="com.test02.AOP.MyAspect"/>

3. 이게 핵심!!
spring AOP에서 프록시를 자동으로 만들어주는 bean이다.
advisor들을 찾아서 알맞은 bean을 proxy로 감싸도록 자동으로 처리
DefaultAdvisorAutoProxyCreator : 모든 bean을 조사하면서, 
Advisor에 설정된 Pointcut 규칙에 해당하는 메서드가 있는지 검사 
<bean class="org.springframework.aop.framework.autoproxy.DefaultAdvisorAutoProxyCreator"/>

4. myAdvisor는 Advise(=공통로직)+Pointcut(=언제 적용할지)를 합친 객체
expression="excution(public * *(..))"은
public으로 시작하는 모든 메서드에 대해
myAdvice의 invoke()를 실행하도록 한다는 뜻.
<bean id="myAdvisor" class="org.springframework.aop.aspectj.AspectJExpressionPointcutAdvisor"><!-- 언제 가로채서 실행할지 표현식으로 작성 -->
<property name="advice" ref="myAdvice"/>
<property name="expression" value="execution(public * *(..))"/> <!-- public * *(..) 이렇게 생긴 메소드가 실행(execution)될때 myAdvice로 호출을 가로채서 실행하겠다. -> invoke실행 -> target 호출-->
													<!-- public * com.test02.AOP.Student.classWork(..) => student만 가로챔 -->
</bean>

Spring06_AOP->com.test02.AOP의 동작 과정
1. 컨테이너가 bean을 만들때 student,teacher 객체를 타겟 객체로 생성. 타겟 객체란: AOP 적용 대상이 되는 일반 객체(빈)
2. DefaultAdvisorAutoProxyCreator가 동작
: 모든 Bean을 조사하면서, Advisor에 설정된 Pointcut 규칙에 해당하는 메서드가 있는지 검사
3. 만약 해당하면?
예를 들어 
<bean id="myAdvisor" class="org.springframework.aop.aspectj.AspectJExpressionPointcutAdvisor"><!-- 언제 가로채서 실행할지 표현식으로 작성 -->
<property name="advice" ref="myAdvice"/>
<property name="expression" value="execution(public * *(..))"/>
</bean>
이 expression은 public 메서드라면 다 적용되는 Pointcut이므로.
Student, Teacher의 public 메서드가 이 규칙에 맞음
4. 그러면 proxy를 생성
-> 스프링은 타겟 객체(student,teacher)를
	Advisor에 지정된 Advice(MyAspect)로 감싸는 Proxy를 만들어서
	컨테이너에 타겟 객체를 감싼 Proxy객체를 최종적으로 등록
	
*student, teacher는 단순이 빈으로 등록된 일반 객체인데, AOP에서 이들이 타겟 객체가 되는 이유는
myAdvisor 빈에 설정한 Pointcut 표현식이 execution(public * *(..)) 이렇게 public 메서드라면 모두 다를 뜻하기 때문에 
Pointcut에 걸리는 빈이 타겟 객체가 된다.

5. 이제 누군가 student.classWork()을 호출하면
6. proxy 객체의 invoke()가 실행됨.
7. MyAspect의 invoke() 실행
8. 타겟 메서드 이전 로직 실행 후 invocation.proceed()호출
9. 실제 타겟(Student)의 classWork()가 실행


프록시 객체(빈) 생성 방법
1. DefaultAdvisorAutoProxyCreator
<bean class="org.springframework.aop.framework.autoproxy.DefaultAdvisorAutoProxyCreator"/>
- Advisor(Pointcut + Advice)를 별도로 만들어서 등록.
- DefaultAdvisorAutoProxyCreator가 등록된 Advisor를 찾아 자동으로 프록시를 생성

2.<aop:config>
<aop:config>
	<aop:aspect ref="myAspect">
		<aop:before method="before" pointcut="execution(public * *(..))"/> 
		<aop:after method="after" pointcut="execution(public * *(..))"/>
	</aop:aspect>
</aop:config>
- @Aspect 필요없이, XML로 Pointcut과 Advice를 지정.

3.<aop:aspectj-autoproxy/>+ @Aspect
- @Aspect로 Advice / Pointcut 정의.
- <aop:aspectj-autoproxy/>가 자동으로 @Aspect를 찾아 프록시를 생성.
- (aspect도 bean으로 등록해야 AOP가 동작할 수 있다. AOP는 스프링 빈에만 적용 가능하기 때문에)

@Before: 타겟 이전에 동작
@After: 타겟 이후에 모든 메소드 실행 후 동작 (try-catch의 finally처럼 예외발생했건 상관없이 항상 실행)
@AfterReturning(pointcut="execution(public * *(..))", returning="returnVal") : 타겟 return하고난 이후에, return값을 returnVal이름으로 받아올수 있다.
@AfterThrowing : 타겟 실행 도중 예외 발생 이후에 실행

JoinPoint란?
@After("execution(public * *(..))")
public void after(JoinPoint join) {
	System.out.println("집에 간다.");
}
"Advice가 실행될 때, 타겟 메소드에 대한 다양한 정보를 담고 있는 객체"
Advice 메소드에 매개변수로 넣으면 스프링이 Advice가 실행될 때 자동으로 넣어주고,
- 어떤 객체의 메소드가 호출됐는지
- 어떤 파라미터로 호출됐는지
- 어떤 메소드가 실행됐는지
같은 정보를 Advice에서 확인할 수 있다.
join.getTarget() : 실제 타겟 객체(ex. Teacher, Student 인스턴스)
join.getSignature() : 호출된 메소드 시그니처 정보
join.getSignature().getName() 호출된 메소드 이름
join.getArgs() : 전달받은 매개변수 배열



@Pointcut 메소드 방식 -> 재사용 가능 (어노테이션 기반 AOP에서만 사용)
기존에는 @Before안에 pointcut을 일일히 넣어줬지만
메소드 방식은 @Pointcut 메소드를 선언해놓으면 @Before에 메소드명만 가져와 재사용할 수 있다.
@Pointcut("execution(public void *(..))") //pointcut 재사용, 메소드 방식
	public void myClass() { //기준점이 된다.
		
}
@Before("myClass()") 
public void before(JoinPoint join) {
	System.out.println("컴퓨터를 켠다.");
}
