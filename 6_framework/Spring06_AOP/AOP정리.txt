AOP
프로그램은 비즈니스 로직(핵심기능)과 공통 관심사(공통기능)으로 나뉜다.
AOP가 이를 깔끔하게 분리하기 위해 존재한다.

AOP 과정
애플리케이션이 실행되면 스프링 컨테이너는 타겟 객체를 감싸는 프록시 객체를 생성하고 이를 빈으로 등록한다.
이렇게 만들어진 프록시 객체가 타겟 객체를 내부에 보관하고 실제 호출을 가로챈다.
이후 타겟 메소드가 호출되면 프록시 객체의 invoke()메소드가 먼저 실행되어
타겟 메소드 전, 타겟 메소드 실행(invocation.proceed()), 타겟 메소드 후 처리를 순서대로 진행하게 된다.
 
AOP XML 설정
1. 타겟 객체(비즈니스 로직 담당) bean으로 먼저 생성
<bean id="student" class="com.test02.AOP.Student"/>
<bean id="teacher" class="com.test02.AOP.Teacher"/>

2. MyAspect클래스가 advise 역할 수행.=> 공통관심사항 실행할 객체!
MyAspect는 MethodInterceptor 구현해서 invoke() 가지고 있다.
<bean id="myAdvice" class="com.test02.AOP.MyAspect"/>

3. 이게 핵심!!
spring AOP에서 프록시를 자동으로 만들어주는 bean이다.
advisor들을 찾아서 알맞은 bean을 proxy로 감싸도록 자동으로 처리
DefaultAdvisorAutoProxyCreator : 모든 bean을 조사하면서, 
Advisor에 설정된 Pointcut 규칙에 해당하는 메서드가 있는지 검사 
<bean class="org.springframework.aop.framework.autoproxy.DefaultAdvisorAutoProxyCreator"/>

4. myAdvisor는 Advise(=공통로직)+Pointcut(=언제 적용할지)를 합친 객체
expression="excution(public * *(..))"은
public으로 시작하는 모든 메서드에 대해
myAdvice의 invoke()를 실행하도록 한다는 뜻.
<bean id="myAdvisor" class="org.springframework.aop.aspectj.AspectJExpressionPointcutAdvisor"><!-- 언제 가로채서 실행할지 표현식으로 작성 -->
<property name="advice" ref="myAdvice"/>
<property name="expression" value="execution(public * *(..))"/> <!-- public * *(..) 이렇게 생긴 메소드가 실행(execution)될때 myAdvice로 호출을 가로채서 실행하겠다. -> invoke실행 -> target 호출-->
													<!-- public * com.test02.AOP.Student.classWork(..) => student만 가로챔 -->
</bean>
