lombok : Getter, Setter,생성자를 어노테이션으로 작성할 수 있게 해줌
*
ojdbc : 오라클 DB에 자바에서 접속하기 위한 JDBC 라이브러리
-> Java와 Oracle DB 통신을 가능하게 해주는 라이브러리

mybatis : 자바에서 SQL을 xml 또는 어노테이션으로 관리하고,
결과를 자바 객체(VO, DTO)에 자동 매핑해주는 SQL Mapper 프레임 워크.
사용 이유: 순수 JDBC로 하면 SQL을 자바 코드에 하드코딩, 파라미터 set, resultSet수동으로 매핑
		귀찮고 유지보수 어렵다.
mybatis는 UserMapper.xml 같은 파일에 SQL 따로 관리 

mybatis-spring : mybatis를 스프링 DI 컨테이너에 통합시켜서
SqlSessionFactory, SqlSession, 트랜잭션 같은 걸
스프링이 자동 관리하게 해주는 모듈.
사용 이유 : 그냥 mybatis 쓰면 SqlSessionFactory 직접 관리해야함.
mybatis-spring 쓰면 @Autowired로 Mapper 인터페이스를 바로 주입받아서 쓸 수 있음.

commons-dbcp : db 커넥션 풀을 제공하는 라이브러리
-> 매번 new Connection()해서 DB에 연결하지 않고,
	미리 여러 개의 db 커넥션을 만들어 풀에 넣어두었다가 필요할때 꺼내쓰고 다시 반환해서 재사용.
예전 XML에서 이렇게 설정했던것을 commons-dbcp가 대신 제공.
<bean id="dataSource" class="org.apache.commons.dbcp.BasicDataSource">
	<property name="driverClassName" value="oracle.jdbc.OracleDriver" />
	<property name="url" value="jdbc:oracle:thin:@localhost:1521:xe" />
	<property name="username" value="scott" />
	<property name="password" value="tiger" />
	<property name="maxActive" value="20" />
</bean>

spring-orm : 스프링이 JPA, Hibernate, MyBatis 같은 ORM 프레임워크를 연동할 때 필요한 지원 라이브러리.
-> 트랜잭션 관리, 예외 변환, 세션 관리 같은 기능을 스프링 스타일로 처리해줌.
