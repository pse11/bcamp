1) pom.xml
:Maven(자바용 프로젝트 관리 도구)에서 프로젝트에 필요한 라이브러리(의존성)를 자동으로 다운로드하고 관리하는 설정 파일.
여기에 설정하는 것:
dependencies : 사용할 라이브러리(jar)
plugins : 빌드/테스트/패키징 도구
repositories : 라이브러리 받을 서버
properties : 자바 버전, 인코딩 등 공통 값

2) web.xml
: 서블릿 컨테이너(톰캣)에서 웹 애플리케이션의 초기 구성을 설정.
여기에 설정하는 것:
DispatcherServlet 등록 -> 스프링 MVC의 프론트 컨트롤러
ContextLoaderListener 등록-> 스프링 전역 설정(applicationContext.xml)로딩
filter 등록 -> 요청/응답 전처리(ex. 인코딩 필터)
servlet-mapping -> 어떤 URL 패턴을 DispatcherServlet이 처리할지 설정

3) WEB-INF/spring/sqls/sql.txt
: 테이블, 시퀀스 생성 SQL문 모아둔 파일
CREATE TABLE, SEQUENCE,
INSERT INTO

4) DTO, DAO, SERVICE, CONTROLLER
:스프링 MVC+서비스 아키텍처 계층 구조.
DTO => 데이터 전달 객체
DAO => DB 접근, SQL 실행(MyBatis board-mapper.xml과 연결)
SERVICE => 비즈니스 로직 처리, 트랜잭션 관리, DAO 호출
CONTROLLER => 사용자의 웹 요청 받아 처리, 서비스 호출 후 View 반환

5)src/main/resources/mybatis/board-mapper.xml
: MyBatis SQL 매퍼 파일.
SQL문을 작성해두고, DAO에서 메서드로 호출.
여기에 설정하는 것:
<mapper namespace="myboard">
<select>,<insert>,<update>,<delete> : SQL문 정의
parameterType, resultType 지정

6) WEB-INF/spring/sqls/config.xml
:MyBatis 설정 파일.
여기에 설정하는 것:
typeAliases : 별칭 설정
settings : 전역 설정(ex. 캐시, 지연로딩)
mappers : 매퍼 xml 등록(Spring에서 mapperLocations에 위임 가능)

7)servlet-context.xml
: 스프링 MVC 설정 파일
DispatcherServlet이 로드.
여기에 설정하는 것:
@Controller 스캔할 패키지
ViewResolver : JSP 경로 설정
파일 업로드(MultipartResolver) 등 웹 관련 빈

8) applicationContext.xml
: 스프링 전역(백엔드) 설정 파일.
ContextLoaderListener가 로드.
여기에 설정하는 것:
@Service, @Repository 스캔할 패키지
DataSource(DB 커넥션 풀)
SqlSessionFactoryBean(MyBatis 연동)
트랜잭션 관리자
