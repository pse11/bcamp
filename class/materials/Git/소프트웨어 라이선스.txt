** 소프트웨어 개발 단계별 용어 **
Alpha 버전(알파) == Canary : 개발자가 완성. 치명적인 버그 가능. --> 실무에서 사용X
Beta 버전(베타) == Community 에디션 : 웬만한 치명적 버그는 잡음. 단 작은 버그는 가능. --> 실무에서 급하면 사용O
RC(Release Candidate : 출시후보판) : 버그 거의 없음. 단 아주 작은 버그는 가능 --> 실무 사용 가능 
Preview (미리보기 판) : 정식 버전과 거의 같음.
정식 버전 == RTM 버전 == GA 버전 == 1.0 버전, Community 에디션(=무료 정식버전)
(배포 안하는 회사도 있음) Patch 버전 : 정식 버전의 버그를 수정 (기능을 추가)
Update1, 2... 버전 : 여러개의 Patch의 묶음.
Service Pack 1, 2..... : 여러개의 Update묶음.
